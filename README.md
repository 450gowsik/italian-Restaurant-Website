# Italian Restaurant Website

This project is a modern, responsive Italian restaurant website built to demonstrate frontend design and user experience skills. The website uses a clean dark theme and interactive components to create a professional, real-world restaurant web presence.

The project contains approximately **330 lines of well-structured HTML, CSS, and JavaScript code**, focusing on layout, styling, and interactivity.

## Features
- Dark-themed navigation bar with logo and smooth navigation links
- Hero section with background image and styled call-to-action buttons
- Interactive menu cards with hover effects
- Image gallery displayed in a responsive grid layout
- Testimonials carousel for customer feedback
- Contact form with basic validation
- Fully responsive design for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to practice frontend web development concepts, responsive design, and UI/UX principles by building a visually appealing business website similar to real restaurant websites.

## Output
Simply open the `index.html` file in a browser and refresh to view the fully styled Italian restaurant website.
